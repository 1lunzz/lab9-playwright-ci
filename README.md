# Лабораторная работа №9 — GitHub Actions CI

Учебное локальное приложение расчета доставки и 12 UI E2E-тестов на Playwright/pytest.

## Правила расчета
- Заказ меньше 10 000 ₸: доставка 1 000 ₸ для города и 2 000 ₸ для региона.
- Заказ от 10 000 ₸ включительно: доставка бесплатна.
- Проверяются 8 корректных вводов, 3 некорректных ввода и сброс формы.

## Структура
- `delivery.html` — приложение.
- `conftest.py` — фикстура открытия страницы.
- `test_delivery_ui.py` — 12 тестовых случаев.
- `requirements.txt` — зависимости.
- `.github/workflows/ui-tests.yml` — CI workflow.

Подробная инструкция запуска, проверки дефекта и защиты находится в `README.txt`.
